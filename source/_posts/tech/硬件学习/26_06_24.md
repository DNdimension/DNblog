## 控制舵机  
有了外接电池就可以上舵机了  
引入Servo.h进行控制，实例化出myservo对象，attach(PIN)方法可以绑定引脚，write方法可以写入机械臂角度。不需要设置为OUTPUT模式  
这里为了节省内存，使用byte(unsigned char)类型，反而被坑了    
{% codeblock sketch_jun23a.ino lang:cpp %}
void loop() {
  for(byte pos=0;pos<=180;pos++) {
    myservo.write(pos);
    delay(6);
  }
  for(byte pos=179;pos>=0;pos--) {
    myservo.write(pos);
    delay(6);
  }
}
{% endcodeblock %}
对于下面的循环,当pos为0，pos--后pos变成255，导致循环无法结束，并且pos等一段时间之后减到180重复下一个循环，看起来就像上一个循环没有执行  
<img src="https://s3.bmp.ovh/2026/06/24/8C77CSXN.webp"  width="45%"/>

下方循环修改为
{% codeblock sketch_jun23a.ino lang:cpp %}
for(byte pos=179;pos;pos--) {
  myservo.write(pos);
  delay(6);
}
{% endcodeblock %}
即可达成目的
